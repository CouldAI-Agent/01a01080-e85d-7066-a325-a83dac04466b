# Clap Clap Little Hands

An interactive Flutter storybook app based on the "Clap, clap, little hands!" song and script.

## Features
- **22 Interactive Scenes**: Step through every scene of the song, from the initial hook to the goodbye end card.
- **Responsive Layout**: Designed to work on mobile, tablet, desktop, and web.
- **Interactive Navigation**: Use the "Previous" and "Next" buttons to navigate the story.
- **Visual Cues**: Each scene features unique emoji visuals and colorful backgrounds representing the actions (clapping, dancing, animals, fast/slow).

## Platforms
Supports iOS, Android, Web, macOS, Windows, and Linux.

## How to Run
1. Ensure Flutter is installed.
2. Run `flutter pub get`.
3. Run `flutter run`.
